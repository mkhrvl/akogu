# Playwright browser

- Use Playwright MCP whenever browser interaction or verification is required.
- Verify behavior in the browser rather than inferring it from code or logs.
- Use normal automated tests instead when browser verification is unnecessary.
- Fall back only when Playwright MCP is unavailable or insufficient.
